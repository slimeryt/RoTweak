Using RoTweak

Where to find controls and what the main parts of the extension do.

The in-page panel

On roblox.com, click RoTweak in the header. The panel lists every feature by category. Toggle a switch to enable or disable it instantly.

  • About — version info and links to this help site.
  • Privacy — streamer mode and Roblox account privacy dropdowns (who can message you, join you, etc.) when signed in.
  • Other groups match the topics on the features page.

Extension popup

Click the RoTweak icon in your browser toolbar for:

  • Quick enable / disable for the whole extension.
  • Connect or Disconnect Roblox.
  • A shortcut to the full Options page.

Options page

Open from the popup or right-click the extension → Options. Same settings as the panel, plus:

  • Search across all toggles.
  • Roblox connection status.
  • Reset — restore default settings.
  • Clear storage — wipe settings, agreement, and login tokens.

Command palette

When Enable command palette is on, press Ctrl+K (Windows/Linux) or ⌘+K (Mac) on any Roblox page.

  • Jump to a game, user profile, catalog item, or Creator Hub page.
  • Run quick actions without hunting through menus.
  • Pick a theme for how the palette looks in settings.

Reimagined pages

Several toggles replace Roblox’s default page with a RoTweak layout. Visit the page normally — if the toggle is on, you’ll see the new design:

  • Profile — magazine-style layout with stats, about, creations, groups, badges.
  • Inventory — grid view with categories and search.
  • Friends — denser list with presence and requests.
  • Avatar — editor-style view with equip and outfits.
  • Transactions — charts, totals, and filters on My Transactions.

On profiles you own, use Customize profile for colors and layout, or Classic profile to temporarily see Roblox’s original page.

On game pages

With Page IDs enabled, open the RoTweak tab on an experience page to copy Place ID, Universe ID, and related IDs. Private server helpers add copy/join shortcuts on private server cards when that option is on.

Servers list

On a game’s Servers tab, enable region and uptime labels to see where each public server runs and how long it’s been up. Server filters let you narrow by region, player count, and more.

Streamer mode

Blurs Robux amounts and shortens displayed names (yours and friends’) to reduce accidental leaks while streaming or recording.

Website chat

With Replace website chat on, the bottom-right chat becomes RoTweak’s version — conversations, friends list, and presence in one place.
