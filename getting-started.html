Getting started

Install RoTweak, accept the agreement, and connect Roblox.

Install (developer / unpacked)

  1. Open your browser’s extensions page (chrome://extensions in Chrome).
  2. Enable Developer mode.
  3. Click Load unpacked and select the RoTweak folder.
  4. Open any roblox.com page and refresh.

First launch

  1. Read and accept the first-run agreement.
  2. Click Connect Roblox and sign in when prompted.
  3. Open the RoTweak panel from the button in the Roblox header.
  4. Toggle features on — most are off until you enable them.

OAuth setup is required for Connect Roblox. See Connect Roblox for Creator Dashboard steps and redirect URI details.

Popup & options

  • Extension popup — master on/off, connect status, link to options.
  • Options page — all settings, Roblox connection, clear storage.
  • In-page panel — same toggles while browsing Roblox, grouped by category.

Updates

After pulling a new version, reload the extension on chrome://extensions, then refresh open Roblox tabs. Roblox site updates sometimes break selectors — if a feature stops working, check for an extension update.
