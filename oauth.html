Connect Roblox (OAuth)

RoTweak uses Roblox Open Cloud OAuth with PKCE — a public client with no client secret stored in the extension.

1. Create an OAuth app

  1. Open Creator Dashboard → Credentials.
  2. Create an OAuth 2.0 app (public / PKCE).
  3. Add scopes: openid and profile.
  4. Set privacy policy URL: https://slimeryt.github.io/RoTweak/privacy.html
  5. Set terms URL (if required): https://slimeryt.github.io/RoTweak/terms.html

2. Redirect URI

Load the unpacked extension once, then copy your redirect URI:

  • Open RoTweak Options — the redirect URI is shown under Roblox connection.
  • Or run in the extension service worker console: chrome.identity.getRedirectURL()

It looks like:

https://<extension-id>.chromiumapp.org/

Paste that exact URI into your OAuth app’s allowed redirect URLs.

3. Client ID

For self-hosted / developer builds, paste the OAuth Client ID into shared/oauth.js:

const CLIENT_ID = "your-client-id-here";

Reload the extension, accept the agreement, and click Connect Roblox.

Never put a client secret in the extension package. Clear storage in options removes local tokens. Revoking the app in Roblox account settings also ends access.

Troubleshooting

  • Redirect mismatch — URI must match character-for-character, including trailing slash.
  • Invalid client — check Client ID and that the OAuth app is approved.
  • Context invalidated — reload extension after code changes, refresh Roblox tabs.
