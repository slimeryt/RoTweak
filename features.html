Interface

Page IDs section

RoTweak tab on games (and ID rows elsewhere) to copy Place, Universe, and User IDs.

Hide sponsored content

Removes sponsored games and promo tiles on home and charts.

Subplaces tab

Extra tab on experience pages listing other places in the same universe.

Optimization

Block analytics & trackers

Stops common third-party tracking scripts on Roblox pages.

Disable link prefetch

Roblox won’t preload pages in the background that you might never open.

Block social embeds

Skips heavy YouTube, Twitter/X, and similar embeds on profiles and feeds.

Block autoplay media

Promo videos and audio won’t start playing on their own.

Lazy-render feeds

Lighter scrolling on long game and list feeds.

Trim home page clutter

Hides big promo banners and carousels on the home page.

Reduce animations

Less motion and transitions across the site.

Pause when tab hidden

RoTweak slows down background work when the tab isn’t visible.

Slower navigation polling

Uses a bit less CPU by checking for page changes less often.
